Production deployment tips

  • 1. HTTPS: Host on Firebase Hosting / Netlify / Vercel / Cloudflare Pages — they give free HTTPS with your domain. Add a _headers rule for HSTS. Only the classroom Wi-Fi + a login gate keeps outsiders out.
  • 2. SQL (50+ users): This demo uses Firebase Realtime DB which already handles thousands of concurrent users. If your institution mandates SQL, migrate the SYNC_KEYS payload to a Node.js + PostgreSQL/MySQL REST API. The front-end logic (state object) stays identical — just swap publishKey/pullLatest with fetch calls.
  • 3. Access control: Restrict by Firebase Rules + custom claims. Optionally whitelist IP ranges of your campus at the hosting layer.
  • 4. Barcodes: Print on adhesive label sheets (Avery 5160 style) — the print sheet scales automatically.
